# Feed

Personal machine-readable feeds generated by scheduled ChatGPT tasks.

## Structure

```text
data/
  nfl/
    latest.json
    archive/
  news/
    latest.json
    archive/
schemas/
  feed-v1.schema.json
AGENTS.md
```

Each feed uses the same versioned JSON format. Consumers should read `latest.json` for the current snapshot and may use dated files under `archive/` for history.

## Feed format

```json
{
  "schema_version": 1,
  "feed": "nfl",
  "generated_at": "2026-09-25T13:30:00Z",
  "items": [
    {
      "id": "stable-item-id",
      "title": "Story title",
      "summary": "Concise factual summary.",
      "published_at": "2026-09-25T12:10:00Z",
      "sources": [
        {
          "name": "Source name",
          "url": "https://example.com/story"
        }
      ],
      "media": [
        {
          "type": "youtube",
          "url": "https://www.youtube.com/watch?v=..."
        }
      ]
    }
  ]
}
```

## Conventions

- Timestamps are RFC 3339 / ISO 8601 in UTC.
- `id` values should remain stable for the same underlying item across regenerations.
- `latest.json` is overwritten on each successful run.
- Historical snapshots should be written to `archive/YYYY-MM-DD.json`.
- Producers must validate against `schemas/feed-v1.schema.json` before publishing.
